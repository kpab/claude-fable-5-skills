# Contributing

PRs welcome. Two rules keep this collection useful:

1. **Evidence over opinion.** A change to a skill should come with a reproducible before/after: the prompt, the output with the old skill text, the output with yours. Fable 5's behavior is the arbiter.
2. **Shorter is a feature.** If your PR makes a skill longer, the burden of proof is on the added lines. Deletions need less justification than additions.

New skills: open an issue first describing the Fable 5 behavior it targets and why none of the existing 10 covers it.
